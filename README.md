








# Job Portal App 📱

A mobile job portal application built with **React Native and Expo** that connects job seekers with companies. Job seekers can explore job opportunities, apply for jobs, and upload their CVs, while companies can post jobs and manage applications.

## 🚀 Features

### 👨‍💻 Job Seeker
- User registration and login
- Browse and search for job opportunities
- View job details
- Apply for available jobs
- Upload CV/resume in PDF format
- Manage profile information
- View messages and application-related information

### 🏢 Company
- Company registration and login
- Company dashboard
- Post and manage job listings
- View job applications and submitted resumes
- Manage company profile
- Chat and coordinate interviews with job seekers

## 🛠️ Technologies Used

- **React Native** – Mobile application development
- **Expo** – Development and build tools
- **JavaScript** – Application logic
- **Firebase Authentication** – User authentication
- **Redux Toolkit** – State management
- **React Navigation / Expo Router** – Navigation and routing
- **Document Picker** – PDF CV selection and upload

### 4. Configure Firebase

- Create a project in the Firebase Console.
- Enable Firebase Authentication and configure the sign-in methods used in the application.
- Add your Firebase configuration using your project's setup.
- Keep sensitive credentials secure and never commit private secrets to GitHub.

### 5. Start the Application

```bash
npx expo start
```

Run the application using Expo Go or an appropriate Android emulator, depending on your project configuration.

## 🔐 Authentication

The application uses Firebase Authentication for user sign-up and login. Users can select their role as a job seeker or company and access the corresponding features.

## 🎯 Project Objective

The objective of this project is to simplify the recruitment process by providing a convenient mobile platform where job seekers can find employment opportunities and companies can connect with potential candidates.
